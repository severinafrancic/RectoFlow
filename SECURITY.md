# Security and privacy

RectoFlow performs local screen acquisition and native clicks under the current
Windows user. Run it only on documents/windows you intend to capture and navigate.
Browser pages and imported manifests are untrusted data. Do not expose captured
documents or configuration paths in public issues. The project has no telemetry.

For vulnerabilities, use GitHub's private vulnerability reporting if available,
or contact the repository owner privately through an available GitHub channel.
Do not publish an exploit containing private documents, credentials or tokens.

The initial prerelease is the maintained development line. Screen coordinates,
button recognition, config writes, recovery and release packaging are material
verification boundaries. Known limits are recorded in docs/COMPATIBILITY.md.
