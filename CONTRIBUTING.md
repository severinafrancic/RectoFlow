# Contributing

Small, reproducible contributions are welcome. Open an issue describing the browser,
Windows version, scaling, navigation mode and expected versus observed behavior.
Use a synthetic document or redact private page content. Never attach tokens, browser
profiles, real document screenshots or personal manifests without explicit intent.

Work in the canonical repository, use a branch, preserve legacy config/manifest
contracts, and test the entire coordinate producer/consumer path. See
[development](docs/DEVELOPMENT.md). Independent review must bind its exact subject;
passing Builder tests do not establish acceptance. Contributions are under MIT.
